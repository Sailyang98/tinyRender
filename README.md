## 1.Bresenham’s line drawing algorithm
在屏幕上画一条线最直观的方式是利用直线方程y = mx + b, 涉及浮点数乘法和取整。
Bresenham的优化方法做到了只用整数加减法就完成线的绘制, 核心思路:
1.假设我们已经画到了像素点 $(x, y)$，下一步 $x$ 肯定会加 1（向右移动）。那么 $y$ 呢?
A: 保持在当前行, 最终坐标$(x+1, y)$
B: 向上跳一行, 最终坐标$(x+1, y+1)$
我们只要看理想的直线离上面的AB两个点哪个更近, 选择更近的就可以了。
算法维护一个误差项, 记录当前位置和理想位置的偏差, 当误差超过半个像素时, 就把y抬高。

关于加载.obj文件的:
.obj文件的每一行由前缀 和 值 组成
* v 0.1 0.1 0.1 : 这是一个顶点坐标, v表示是顶点,后面分别是x y z坐标
* vt 0.1 0.1 0.1 : 这是一个纹理坐标索引, vt表示是纹理坐标,后面分别是x y z坐标
* vn 0.1 0.1 0.1 : 这是一个法线坐标, vn表示是法线,后面分别是x y z坐标
* f 1622/1692/1622 1674/3040/1674 1625/1791/1625: 这是一个面数据, 标准格式为f v1/vt1/vn1 v2/vt2/vn2 v3/vt3/vn3, 后面的正整数是前面提到的v vt vn数据的坐标索引(f离记录的下标从1开始, 所以如果加载v/vt/vn数据时填充到从0开始的数组里, f这边记录的下标要-1才能对应的上)

加载.obj文件用 ifstream + stringstream很方便.
